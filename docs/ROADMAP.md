# 로드맵

각 단계는 CLI로 실행해 결과를 확인할 수 있는 상태로 끝낸다.

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| 0. 정의 | 저장소, 아키텍처, 도메인 모델, 서비스 시그니처 | 완료 |
| 1. 물건 검색 | 온비드 OpenAPI 어댑터, SQLite 저장소, `search` CLI. 이후 법원경매 어댑터 | 지역·종류 조건으로 공매 물건 목록이 저장되고 조회됨 |
| 2. 시세·역세권 | 국토부 실거래가 어댑터, 카카오 로컬 어댑터, 시세 추정, 역 거리 | 물건 한 건에 대해 추정 시세와 가장 가까운 역 3곳이 나옴 |
| 3. 자료 수집·파싱 | 문서 다운로드, 파일 저장소, 등기부 업로드, Claude 기반 구조화 추출 | 매각물건명세서에서 임차인·권리 목록이 구조화되어 나옴 |
| 4. 권리분석 | 말소기준권리, 인수·소멸, 임차인, 배당 시뮬레이션, 위험 플래그, `rules/` 기준표 | 대표 사례 테스트(선순위 임차인, 전세권, 가처분 등) 통과 |
| 5. 수익성·리포트 | 비용·세금 계산, 시나리오, 입찰 상한가, 점수, 리포트 출력 | `analyze` 한 번으로 종합 리포트 생성 |
| 6. API·웹 | FastAPI, Next.js, 지도 화면 | 브라우저에서 검색 → 분석 → 리포트 확인 |
| 7. 자동화 | 관심 조건 저장, 주기 수집, 새 물건·기일 변경 알림 | 저장한 조건의 새 물건이 자동으로 분석됨 |

## 시작 전에 준비할 것

- 공공데이터포털 계정과 활용 신청: 온비드 공매물건 조회, 국토교통부 실거래가(매매·전월세), 건축물대장
- 카카오 개발자 계정과 REST API 키
- Anthropic API 키 (Phase 3부터)
- (선택) TMAP 앱 키
