# auction-lens

부동산 경매·공매 물건을 찾고, 관련 자료를 내려받아 권리분석·수익성 분석·시세 비교·역세권 분석까지 한 번에 수행하는 앱.

## 무엇을 하나

1. **물건 검색** — 법원경매, 온비드(공매) 물건을 조건으로 검색
2. **자료 수집** — 매각물건명세서, 현황조사서, 감정평가서 등 다운로드 및 구조화
3. **권리분석** — 말소기준권리, 인수/소멸 권리, 임차인 대항력, 배당 시뮬레이션
4. **수익성 분석** — 취득 비용, 세금, 대출을 반영한 시나리오별 수익률과 입찰 상한가
5. **시세 비교** — 같은 지역의 실거래가·매물 호가와 비교
6. **역세권 분석** — 가까운 지하철역까지의 거리와 도보 시간

## 현재 상태

Phase 0 — 구조와 인터페이스만 정의된 상태. 서비스 함수는 시그니처만 있고 구현은 로드맵 순서대로 채운다.

## 개발 환경

```powershell
cd backend
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
pytest
```

API 키는 `.env.example`을 `.env`로 복사해 채운다.

> 권리분석·수익성 결과는 투자 판단을 돕는 참고 자료이며 법률·세무 자문이 아니다.
